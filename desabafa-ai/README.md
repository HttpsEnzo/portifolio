# Desabafa.ai — protótipo mobile

App web progressivo (PWA) com o fluxo do protótipo: Boas-vindas → Ambiente seguro → Como você está se sentindo → Buscando → Deu match → Chat anônimo (com botão Ajuda para psicólogo parceiro, denúncia e diretrizes).

- Todos os gráficos são vetoriais (SVG): nítidos em qualquer densidade de tela.
- Abra `index.html` no celular e use "Adicionar à tela inicial" para instalar como app (funciona offline quando servido por HTTPS, ex.: GitHub Pages).
- No computador, aparece dentro de uma moldura de celular.
